# Control Tower Human V2 — 2차 정보구조 개선 (2026-11-15)

## 범위
- 투자자산 컨트롤타워 **인증 후 Human UI** 전용, Observatory 시장 화면과 별개.
- 4개 계좌(TOSS/ISA/PENSION/IRP)만 표시. TRI-POD는 Toss 내부 전략 슬리브이며 자산 합산 대상 아님. 폐기된 AUTOBOT 부활 금지.
- 원천/API/주문/전략엔진/금융 산식은 그대로 사용하고 기존 화면에 **읽기 전용** 정보를 배치.

## 2차 화면
- 오늘 화면: 계좌별 당일손익 영향 4행, 손익규모 막대와 측정근거, 계좌성과·보유분석·성과분석·TRI-POD·데이터품질 바로가기.
- **동일 기간, 4계좌 손익이 모두 존재할 때만** 손익규모순 정렬. 이 조건이 충족되지 않으면 계좌 원래 순서를 보존하고 '계좌별 참고 · 합산 비교 불가'라고 표기.
- 계좌 원천 today_pnl이 없으면 '자료 없음'이며 0원으로 위장하지 않음. 값의 측정방식은 BROKER_MEASURED/MODELED/확인 필요로 구분.
- 막대는 해당 snapshot의 4개 계좌 중 가장 큰 절대 손익 대비 상대 크기이며, 포트폴리오 수익률·위험 점수·거래 신호가 아님. 누락 시 빈 막대.
- 데스크톱 폭 1080 이상에서는 요약 정보와 계좌별 영향 영역을 2열로, 모바일에서는 세로 배치.
- V2 기본, ?ctui=v1 복구 가능. 기존 모든 탭/드릴다운은 유지. 전환은 원래 탭 handler를 재사용.
