# US yield index charts

The rates panel offers intraday, daily, weekly and monthly views of the same Yahoo Finance / Cboe yield indices (^IRX, ^FVX, ^TNX, ^TYX). These are market yield indices, separate from the official Treasury daily curve elsewhere on the page. Never substitute Treasury futures prices for yields. The separate 2-year source link remains explicit because this index family has no 2-year tenor.

Intraday defaults to the latest observed **America/New_York trading date**; the axis and tooltip show full KST dates and times. DST is handled by IANA time zones. A Korean calendar date can contain the end of the preceding US session and the start of the next one: for example the stored 2026-10-15 KST data have no bars between 03:55 and 21:20. The optional Korean-date view preserves and explains this gap. Gaps over 15 minutes remain null; no prices are interpolated. Explicit x bounds stop the chart extending into the preceding or following day.

Daily history uses the source's actual daily closes over up to ten years. Only US dates completed by a conservative 16:30 New York cutoff are included. This cutoff is a cache/retrieval rule, not a guarantee of exchange publication or holiday coverage. The last actual data date is always displayed. Daily timestamps are source bar anchors, not exact observation/closing clocks, so daily/weekly/monthly freshness is labelled by US trading date rather than a fabricated KST close time. Daily retrieval runs once per completed-date cache key, retries on failure and is independent of intraday retrieval.

Weekly uses the last actual daily point in each Monday-start week; monthly uses the last actual daily point of each calendar month. Filter by the selected US as-of date before aggregation. The last week/month may be incomplete. Weekends and holidays do not produce synthetic points. Chart high/low are over the displayed observations, not intraperiod market extremes. Basis points equal the absolute percentage-point change from the first displayed observation times 100.

The collector preserves 30 calendar days of intraday history and the last good daily history separately for each tenor. Failed components retain their data and report STALE/UNAVAILABLE without blocking other tenors or data sources. The supplemental refresh and independent scheduled workflow publish the same additive V1 document. Published JSON polling is not a new source collection; the top-level data refresh starts source collection.

Validation: Python covers source contracts, caching, incomplete-session filtering and independent failures; Node covers date boundaries, DST, gaps, basis points and period aggregation; responsive CI checks all four grains at 360/390/430/800 widths and retains the graph after a read failure.
