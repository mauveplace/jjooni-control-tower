# 승인 후 실제 화면 추가 점검

점검일: 2026-10-26 KST. 사용자 승인으로 운영 브라우저에서 실제 계좌 화면을 열고 Overview, 계좌성과, TRI-POD, 보유분석을 직접 전환했다. 최초 승인 정보는 보안 입력 경로로 전달됐으며 코드·문서·테스트에 포함하지 않는다. 개인 계좌값과 내려받은 검수본도 이 저장소에 포함하지 않는다.

## 실화면에서 추가 확인한 결함과 수정

1. **폐기한 화면 참조로 렌더 중단**: 삭제된 비교 카드와 AUTOBOT 보유 목록을 기존 셸 렌더가 참조해 ReferenceError를 발생시켰다. 복호화한 문서의 실행 스크립트에서 확인된 폐기·교체 요소 8개에 대한 DOM 쓰기만 존재 여부를 검사한다. 재진입 검수에서 발견한 교체 전 overviewMovers 참조도 같은 범위로 보호한다. 현재 계좌의 오류를 포괄적으로 숨기거나 AUTOBOT 데이터를 재활성화하지 않는다. 암호화 원본 자체의 재발행과 내부 타이머 제거까지 완료했다는 뜻은 아니다.
2. **USD가 있는데 환율 기여도는 없음**: 계산기가 옛 prev_close 필드만 사용했다. 현재 원본의 holding_price_effect에서 CALCULATED 상태, 종목·통화·수량·현재가와 출처가 일치하는 기준종가를 사용한다. 누락·불일치는 제외하고 확인 종목 수를 표시한다. 가격 수익률로 종가를 역산하지 않는다. 실제 검수본의 USD 7개 종목이 모두 계산되고 분해 오차는 수치 허용범위 내였다.
3. **시세 근거 누락을 장전으로 오표시**: 국내 정규장 시세 인쇄 여부를 확인하지 못하면 시간에 관계없이 PRE를 반환했다. 개장 이후 미확인은 ‘확인필요’로 구분한다. 휴일·거래일을 임의 추정해 LIVE/CLOSE를 만들지 않는다.
4. **보유분석의 현재 자료와 과거 자료 혼재**: 최신 자산 아래 구형 손익 0원, 과거 기준 벤치마크·성과표가 남았다. 같은 Canonical 4계좌 원본의 계좌별 NAV와 보유수량·평가액·비중을 표시한다. 검증 대기 중인 과거 성과는 현재 값으로 노출하지 않는다. 가격변동과 계좌 전체 투자손익도 구분한다.
5. **누적손익 미확정인데 수익률만 표시**: 공통 누적 계산에서 손익을 확인할 수 없으면 같은 지표의 수익률도 미확정으로 유지한다. 원금이나 누적손익을 만들어내지 않는다. 실화면의 공통 계좌성과 렌더도 같은 손익 확인 조건으로 수익률을 표시한다.

6. **반복 렌더의 숫자 덮어쓰기**: 검증 계좌 연결 이후 구형 셸이 손익·계좌 카드를 다시 쓰지 못하게 한다. 낙폭 경고가 상위 그리드로 올라가 다른 시장 등락률을 가리는 것도 해당 낙폭 카드 범위로 제한한다.

7. **삭제된 비교 차트 호출**: 실제 재진입에서 compareChart가 제거된 뒤 drawCompare가 null에 쓰는 TypeError를 확인했다. 해당 DOM이 없으면 그 차트 함수만 종료하며 나머지 렌더를 계속한다.

## 검증

- Node 265개, Python 209개 로컬 검사 통과.
- 브라우저 회귀 검사: 폐기 요소가 없는 합성 암호화 화면에서도 현재 화면 렌더가 이어짐, 기기 승인 복원, USD 기준가격 정상/누락 전환, 현재 보유분석과 과거 원장 분리, 390/820/1363 폭. CI와 운영 검증은 해당 PR 결과를 확인한다.
- 실제 사용자 단말에서 최초 제보한 오류 문구는 수집하지 않았다. 이번에 실제로 확인한 것은 운영 브라우저의 위 ReferenceError와 화면 불일치다.
