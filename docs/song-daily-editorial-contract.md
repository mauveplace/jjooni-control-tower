# 일일시황 구성·검증 계약

2026-11-03부터 적용. 송팀장 투자노트 Vol.39의 설명 순서(요약, 숫자 대시보드, 핵심 이슈, 이면과 해석, 다음 확인)를 참고한 독립 시장 리서치다. 원문 복제·작성자 사칭·발언 창작을 하지 않는다. 과거 원문의 수치를 오늘 값으로 재사용하지 않는다. 이 문서가 과거 ①~⑧ 구성 안내보다 우선하며 기존 자료 범위·개인정보 경계·매매 규칙은 유지한다.

## 공개 일일시황의 8개 섹션

다음 제목을 정확히 사용한다.

1. `## ① 오늘의 시장 이야기`: 오늘 달라진 핵심 원인을 연결된 글로 설명. 8줄 이내 첫 화면과 사실/해석 경계를 유지.
2. `## ② 시장 한눈에`: 지수·변동성·금리·환율·원자재, 1D/1W/1M/3M 비교와 기준일·원천. 시장폭·집중도·심리는 확인 수준을 표시.
3. `## ③ 핵심 이슈 깊이 읽기`: 중요한 3~5개를 고른다. 각 이슈에 `**핵심 숫자:**`, `**무슨 일이 있었나:**`, `**왜 중요한가:**`, `**반대 해석:**`, `**다음 확인:**`을 모두 두고 숫자 → 원인 → 투자 의미 → 반론 → 확인 지표로 설명. 자료가 없으면 무엇이 미확인인지 설명하며 발언·숫자를 만들지 않는다.
4. `## ④ 글로벌·한국 시장`: 한국·아시아 동일 현지 완료 세션, 미국 마감과 시간차, 수급·신용·유동성 구분.
5. `## ⑤ AI 산업·기업실적`: 반도체/메모리/전력 등을 구분한 ETF 프록시 1D/1W/1M·5MA/20MA, 공식 실적·경영진 전망·콜 확인 범위. 순수 산업지수와 보조 프록시 구분.
6. `## ⑥ 주요 일정`: 실제 확인한 경제지표·기업 IR 일정, 예정과 발표완료를 구분. 모르는 KST 시간은 확정하지 않음.
7. `## ⑦ 투자전략·위험점검·복기`: 조건부 관찰, 비공개 계좌 게이트·기존 PB 룰, 원문에 고정한 전일 가설 채점. 미확인 값을 사용해 매매 신호를 창작하지 않음.
8. `## ⑧ 원천·데이터 감사`: 실제 읽은 출처·기준시각·결측·전회차 정정·공개 게시 검증 결과.

수치 누락을 막연한 missing 목록으로 대체하지 말고 현재 공개 원천을 직접 재조회한다. 접근/날짜/상품 충돌을 해결하지 못한 항목만 구체적인 이유와 함께 결측으로 남긴다. 정상 자료를 모두 지우는 식의 정정은 하지 않는다.

## 완료 세션과 가격 검증

- 뉴욕 타임존을 사용한다. 미국 정규장 16:00 ET(EDT KST 05:00, EST KST 06:00), 조기폐장 13:00 ET. `tools/observatory_session.py`의 휴장·15분 유예와 `expected_completed_session`을 공유한다. 일봉의 날짜나 새 generated 시각만으로 FINAL을 만들지 않는다.
- `DATA AS OF` 날짜, 검색 스니펫, 동적 페이지의 Last 하나만으로 종가를 확정하지 않는다. NDX·SOX는 동일 완료 세션의 공식 값과 독립 시계열을 교차확인한다. 가격이 맞아도 동적 화면의 Previous Close/0.00%가 모순되면 같은 원천의 직전 완료 종가로 등락을 계산한다.
- 1주/1개월/3개월이 5/21/63거래일인지 달력 기간인지 명시한다. 금리 변동은 bp, 가격 변동은 %로 구분한다. ETF·선물 월물·현물과 정산/장중/종가를 혼합하지 않는다.
- 한국·아시아 일봉은 거래소 현지 타임존으로 날짜를 판독한다. 미국 동부 날짜를 그대로 붙이지 않는다.
- 검증 불일치이면 해당 값과 이에 기대는 해석을 보류한다. 다른 정상 원천까지 삭제하거나 audit PASS로 독립 검증을 대신하지 않는다.

## JSON·자동 게시

기존 JJOONI_MORNING_BRIEF_V1을 유지하고 `editorial_contract`를 추가한다.

```json
{
  "version": "SONG_INSPIRED_DAILY_V1",
  "reference_name": "실제로 참고한 자료명 · 구성 참고",
  "reference_date": "YYYY-MM-DD",
  "verified_at_kst": "YYYY-MM-DDTHH:mm:ss+09:00",
  "close_checks": [
    {"symbol":"NDX","session_date":"YYYY-MM-DD","status":"VERIFIED","close":100,"previous_close":101,"change_pct":-0.990099,"observation_type":"REGULAR_SESSION_CLOSE","source_urls":["https://indexes.nasdaq.com/Index/Overview/NDX","https://query1.finance.yahoo.com/v8/finance/chart/%5ENDX"]},
    {"symbol":"SOX","session_date":"YYYY-MM-DD","status":"MISSING","reason":"동일 완료 세션 독립 검증 실패"}
  ]
}
```

`VERIFIED`는 실제 조회 증거가 있을 때만 사용. `MISSING/CONFLICT`도 허용하되 사유와 해석의 제한을 본문에 표시한다. 검증시각을 사후에 꾸미지 않는다. 새 형식 검증은 2026-11-03 이후 보고서에 적용하고 이전 보관본은 원문 그대로 보존한다.

채팅과 공개본은 동일한 완성 본문을 사용한다. 이미 해당 날짜 자료가 게시돼도 제목·메타·본문·검증 노트를 함께 정정하고 latest/날짜별/index를 한 커밋으로 저장한다. `python tools/validate_morning_brief.py`와 CI를 통과한 후 main 병합·Pages 배포·실제 외부 JSON·화면 재조회까지 확인해야 반영 완료다. PR이 열려 있거나 CI만 통과한 상태를 배포 완료로 보고하지 않는다.

월요일 통합판은 기존 PART A+B 내용과 비공개 게시 경로를 유지하되 같은 설명 원칙과 원천 검증을 적용한다. 실행시간·요일·별도 알림은 변경하지 않는다. 공개 계좌정보·주문·원금/실현손익 수정은 허용하지 않는다.
