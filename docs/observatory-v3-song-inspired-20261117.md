# JJOONI Market Observatory V3 — 송팀장 시황의 읽기 구조를 제품 UX로 확장

**상태:** 독립 ROY 리뷰 및 사용자 실기기 확인 전 `?ui=v3` opt-in preview / V2 기본 유지.

## 변경 이유와 목표

2026-11-17 사용자가 제공한 송팀장 *일일 시황 분석자료*는 큰 지수 숫자, 11개 업종 가로 막대, TRIPOD/BIPOD/NOPOD 단계 비교, 실제 NDX 기준선과 위치 표시, 매크로·기업 이슈, 다음 주 일정 등을 편집형 인포그래픽으로 보여준다. 기존 Observatory는 지표와 조건은 있으나, 왜 중요한지/현재 어디에 있는지가 한눈에 안 보였다. V3는 완전 새 데이터 파이프라인 대신 현재 완료일봉 SSOT 위에 표시 레이어를 더한다.

## UI 의사결정

- **메인 방향:** 편집형 시장 터미널 — 잉크 블랙(`#17191c`), 결정 강조 옐로(`#f5cf25`), 담백한 종이 배경(`#f5f5f1`), 흰색 카드, 명확한 표 구분. 대시보드에 노랑을 남발하지 않는다.
- **기존 시장 부호 보존:** Observatory 한국식 상승 빨강 / 하락 파랑을 그대로 유지. 송팀장 참고 사진의 상승 초록/하락 빨강을 함부로 뒤섞지 않는다.
- **상태색과 시장 움직임 분리:** 공식/참고/지연/불일치/미검증의 의미는 색만으로 전달하지 않는다. 노랑 브랜드 강조를 공식 검증 완료로 오인하지 않도록 상태 문구를 병기.
- **정보 우선순위:** ① 핵심 시장 지수 ② 오늘의 인과 판단 및 데이터 위험 ③ TRI-POD 현재 목표·4개 기준점 ④ 미국 업종 11개 강약 및 한국·테마 상세 ⑤ 세부 지수/금리/환율/원자재 ⑥ 8개 섹션 시황 원문과 일정.
- **모바일:** 390px에서 상단 한 번의 시장 시선→판단→TRI-POD, 하단 **5개 탭 1개**(오늘·시장·전략·일정·시황), 내부 세부 탭은 기존 서브 메뉴 사용. 터치 높이 ≥44px, 넘치는 표는 내부 스크롤만.
- **NO-POD 분리:** 하방 레짐 전환 후보선(MA250×0.95)은 쭈니 NO-POD 보조전략의 실제 진입일 고정 기준점·손절선과 동의어가 아니다. 눈금 옆 NO-POD 상세 버튼으로 기존 별도 원장 탭에 연결한다.
- **전략 눈금:** 하방 `MA250×0.95`, 현재 NDX, 상승 재진입 참고 `MA250×1.01`, TRIPOD DD -9% 복귀 필요선. 실제 가격 간격으로 위치를 배치하고 점과 숫자 4개 모두 유지. 가격선만 넘으면 즉시 전략 전환한다고 쓰지 않는다. 상승 레짐 TRIPOD은 VIX10＜28 및 DD 조건, 하락 레짐 NOPOD은 VIX10≥18 조건.
- **시황:** 8섹션 상세 논리와 검증 이력/발행 아카이브는 기존 그대로. 신규 요약은 `morning-brief/latest.json`과 동일 세션 `daily-glance.json` `daily-market-pulse.json` `sector-rotation-brief.json`의 공개 검증 소스로만 읽음.

## 원천 경계

- 제공자 완료일봉은 **정식 Nasdaq 공식 종가 독립검증**과 다르다. `daily-market-pulse FINAL`은 세션 정합성 확인, 공식 가격 정확성 검증 아님.
- V3 화면 원장은 `freshness.groups.market=LIVE`, 시황 미국 완료세션·TRI-POD 날짜·가격 교차 일치, `consistency=OK`, `no_trade=true`, `freshness.generated_kst` 경과 2시간 이내일 때만 기준선을 시각화한다. 미수집/세션 불일치 시 **확인 대기** 표시. 상태파일 점검시각 2시간 경과 시에는 최신값이라고 주장하지 않고 마지막 검증 완료 세션·원천 시각을 명시한 **과거 완료 일봉 참고값**으로만 기준선을 유지하며 `최신성 재확인 필요`를 노출. 해당 값으로 거래 신호 확정 금지.
- 섹터 34개/US11/KR10/테마13의 완료세션과 수치가 맞을 때만 업종 11개 가격 강약을 표시. '자금 유입'으로 추론하지 않는다.
- **변경 불가:** TRI-POD 산식/실거래/계좌/자동주문, 기존 수집·검증 정책, V1/V2 기능과 기본 진입 경로.
- 기존 NDX 공식 검증 표기 수정 PR #516은 별도 개발 중인 문제다. 배포 판단 시 충돌 및 시각적 경고 수준을 대조해야 한다.

## 기능 배치

| 화면 | V3 변화 | 기존 기능 |
|---|---|---|
| 오늘 | 검정·노랑 시장 종료 요약, NDX 4개 기준점 레일, S&P500 11개 강약 막대, 기존 판단/경고 카드 재정렬 | 원장 1D/1W/1M, 오늘 시황, 위험 경고 |
| 시장 | 숫자·기준일·신뢰 상태 가독성, 표/차트 밀도 정리 | 지수·공식 거시·금리·원자재·FX·ETF |
| 전략 | 동일 세션 NDX 기준 레일을 TRI-POD 화면에도 제공, 전략별 목표 구분 | 송팀장 공식 전략과 쭈니 NO-POD 연구 분리 |
| 일정 | 제목 대비/일정 표 구분/터치 타깃, 공통 카드 톤 | 기존 캘린더·원천 갱신·편집 |
| 시황 | 검정·노랑 8섹션 보고서 상단 지수·섹터·TRI-POD 시각요약 | 8개 분석 섹션과 원문 아카이브, 정정·ROY 범위 |

## QA 및 리뷰 게이트

1. V1 `?ui=v1` / V2 `?ui=v2` 기본 작동, `?ui=v3` 명시 진입 후 V2 복귀 가능.
2. V3 모바일 390, 태블릿 800, PC 1363에서 5개 메뉴 하나/수평 오버플로 없음, 실제 브라우저 JS 오류 0.
3. 최신 공개 시황만 동시 세션 소스의 시각요약을 받고 과거 보관본은 원문 그대로. 소스 누락 시 안내만, 예전 값 재사용하지 않음.
4. 기준점 4개 실제 원장값 일치, NDX/MA250/VIX10/DD 값 교차, NOPOD 조건 빠짐없음, 공식 독립 검증 전 매매 확정 금지.
5. ROY는 코드 PASS뿐 아니라 색채 대비, 한 화면에 너무 많은 정보/가짜로 확정된 인상, 모바일 실제 터치/스크롤, 기존 V2 주요 기능 퇴행을 독립적으로 지적.
6. **사용자 실기기 확인과 ROY 검증을 완료하기 전에는 기본 V3 전환 및 운영 완료를 선언하지 않음.**
