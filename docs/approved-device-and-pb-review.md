# 승인 브라우저와 PB 검수본

승인한 브라우저는 암호화된 기기 승인을 로컬에 보관하고 다음 방문부터 입력 없이 화면을 엽니다. 종전 30일 만료는 제거했습니다. 기존 유효한 승인은 자동 이전하며, 이미 만료된 승인을 되살리지는 않습니다.

새 브라우저는 최초 한 번 기존 Control Tower 비밀번호로 승인해야 합니다. 승인 정보는 다른 브라우저·기기로 자동 전달되지 않습니다. 시크릿 모드, 브라우저 데이터 삭제, OS의 저장소 정리, 비밀번호 변경 후에는 재승인이 필요할 수 있습니다. 기기 지문을 신원 인증으로 사용하지 않습니다.

통신 장애·게시 파일 이상은 기기 승인을 지우지 않습니다. `다시 열기`로 재시도할 수 있습니다. `기기 승인 해제`는 이 브라우저의 승인과 세션을 제거합니다. 비밀번호가 실제로 맞지 않는 경우 재승인 화면으로 전환합니다.

## 로이·짱구에게 화면 검토 요청

1. Control Tower를 연 뒤 검토할 탭과 그래프를 표시합니다.
2. `PB 검수본 저장`을 누릅니다.
3. 저장된 HTML 파일을 해당 AI 채팅에 첨부하고 검토를 요청합니다.

파일에는 저장 시점 화면·그래프 이미지와 연결된 canonical 계좌 스냅샷이 포함됩니다. 가능한 외부 스타일은 내장합니다. 스크립트·폼·이벤트를 제거하고 비밀번호·인증 토큰을 내보내지 않습니다. 계좌 정보가 포함되므로 사용자 지정 상대에게 전달합니다. AI는 파일을 로그인 없이 읽을 수 있지만, 해당 파일은 실시간 사이트 접속권한이나 갱신 기능을 제공하지 않습니다. 다른 탭의 화면 검토가 필요하면 해당 탭에서 다시 저장합니다.

스냅샷 미연결 상태는 `계좌 스냅샷 미연결`로 표시합니다. 파일 저장 시각은 원천 데이터의 최신성을 보장하지 않으므로 snapshot 및 계좌 기준시각과 품질을 함께 확인합니다.

## 검증

- `node --test tests/device-trust.test.cjs`: 승인 유지·legacy 이전·origin/변조·명시 해제.
- `node tests/device-entry-e2e.cjs`: 합성 암호화 화면으로 모바일 최초승인·새탭 입력없는 열기·통신장애 재시도·복호화실패·해제·PB 파일 무인증 열기를 검사합니다. 실계좌 비밀번호는 사용하지 않습니다.
