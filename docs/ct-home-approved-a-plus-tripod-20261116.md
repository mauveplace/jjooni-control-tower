# 형님 승인 A안 + TRI-POD 요약 / 로이 1차 피드백 반영안

2026-11-16 17:34 KST: "ㅇㅇㅇㅇㅇㅇㅇ 좋아 저기에 트라이팟만 추가해서 넣어줘 로이판단받고 진행해".
원칙: A안의 '판단형 홈'을 유지하면서 전략 요약 카드를 한 장 추가한다. 사용자 의도와 달리 NAV 관측 그래프를 임의로 완전히 삭제하지 않는다. 그러나 ROY #505 의견대로 데이터 왜곡·스크롤 비용은 방지한다.

## 첫 화면 읽기 순서
1. **기존 NAV Hero(한 군데만)**: 계좌 범위 4계좌, source snapshot, 지연/불일치 등. 새 NAV hero 중복 생성 금지. 기존 암호화된 hero의 실제 동작은 외부에서 미검증.
2. **오늘 투자 변화**: 합산 같은 기간의 투자손익과 순입출금 명확히 분리; 불완전 시 비교불가 사유 한 줄. 새 성과 데이터 계산 금지.
3. **TRI-POD · 전략 요약(추가)**: 공식 검증된 전략 일별 신호일 때만 레짐, 목표 포트폴리오, 조치 및 최대 3개 핵심 조건(52주 낙폭, NDX/MA250, VIX10). 여기서 말하는 '목표'는 **실제 보유/실제 매매/운용 수익이 아님**. 기준일, 신선도, 마지막 검증 출처 반드시 표시. `HOLD_NO_TRADE`는 '신호상 유지(주문 없음)'으로 번역.
4. **4계좌 구조**: NAV·비중 의미 고정, 검증된 동일기간 당일 손익만 텍스트 추가; TRI-POD는 Toss 내 전략으로 별도 계좌 합산 금지. 각 행은 해당 기존 계좌 탭으로 이동.
5. **자산 변화 그래프**: 최하단 접힌 요약 또는 짧은 참고용 영역으로 보존, 상세 그래프는 성과 탭; 시작/최근 NAV, 데이터 포인트 수와 공백, '입출금·환율 포함 · 투자손익/수익률 아님'을 명시. 7일 미만 또는 원천불일치/오래된 데이터면 차트 숨김. 유효한 일별 시계열은 실제 관측값만 표시하며 Y축 시작/최대값 또는 정확한 시작/종료 라벨을 함께 배치.

## TRI-POD 권위 소스
기존 `tripod-daily-freshness-v35.js`가 검증 완료 후 내보내는 `window.__JJOONI_TRIPOD_DAILY_FRESHNESS_V35.last`의 `trusted`와 `jjooni:tripod-daily-verified` 이벤트를 활용하고 **검증 로직을 중복 구현하지 않는다**. `trusted=false`일 때 현재 목표/액션/임계값을 절대 표시하지 않는다. 선택된 완료시장 일봉의 `regime, target, action, vix10, drawdown_52w_pct, ndx/ma250`만 가져오도록 V35 publish payload에 필드를 읽기전용으로 확장(별도 테스트).
공식 운용 계좌의 실체결 포지션과 시장 계산 신호를 동일시하지 않음. 'TRI-POD', 'BIPOD' 등 모드 라벨을 새로운 문자열 파싱으로 만들어내지 않고 신뢰 가능한 authoritative mode 필드 없으면 전략 목표를 그대로 보여줌.

## UX
- 모바일(390px): 총 NAV·당일 변화·TRI-POD 상태가 1회 스크롤 안에 보이게. TRI-POD 아래 링크는 새 글로벌 메뉴가 아닌 카드 내 '전략 상세' 하나만. 모바일 하단 5탭 유지.
- 데스크톱: NAV/손익과 TRI-POD 2열 구성; QuickPaths는 상단 메뉴와 중복되므로 제거.
- 의사결정 강제 버튼 금지: 매수/매도·주문 없음, read-only.
- 신호 지연·기준일 불일치·권위검증 실패 시 경고 1줄 'TRI-POD 검증 대기'; 이전 확정 목표를 현재 신호로 표시 금지.
- 모든 숫자는 원천 데이터와 기준일 표시, 상승/하락 색으로 거래 유도하지 않음.
