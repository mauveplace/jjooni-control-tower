## Protocol gap found while preparing this probe

`ai-collab/coordinator.py` only accepts `ROY` and `JJANGGU` in `required_reviewers`. A ROY-originated task therefore cannot name JJOONI as its required reviewer, and listing ROY would make the ROY routine review its own PR. This probe lists `JJANGGU` as a placeholder. A follow-up task should add an explicit `USER_TO_ROY` rule (e.g. allow `JJOONI` as required reviewer when `origin == USER_TO_ROY`, and make the ROY routine skip PRs authored by a ROY session).
